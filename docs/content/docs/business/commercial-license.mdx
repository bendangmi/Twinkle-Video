# 商业授权

Twinkle Video 社区版采用 AGPL-3.0。遵守 AGPL-3.0 并履行对应源代码公开义务时，可以免费使用和商用；企业只运营自己的产品且不希望公开受协议约束的代码时，可以申请自营闭源商业授权。

| 授权类型                    |                   价格 | 适用场景                                                                   |
| --------------------------- | ---------------------: | -------------------------------------------------------------------------- |
| AGPL-3.0 社区版             |                   免费 | 按 AGPL-3.0 履行对应源码义务后使用、修改、联网运行、分发和商用             |
| 企业自营闭源年度授权        |     人民币 3,299 元/年 | 一个企业主体运营一个自有网站、SaaS、应用或内部产品，不向第三方交付整套系统 |
| 企业自营闭源永久授权        |        人民币 7,999 元 | 一个企业主体永久闭源使用授权书列明的版本，不自动包含后续版本               |
| OEM / 贴牌 / 第三方闭源交付 | 不在标准公开价格方案内 | 未取得单独书面授权前不得转售、贴牌或向第三方闭源交付                       |

## 如何选择

- 需要按年闭源运营一个自有产品：选择企业自营闭源年度授权。
- 需要长期固定使用授权书列明版本：选择企业自营闭源永久授权。
- 要给甲方私有化部署、销售二开系统、贴牌或向第三方闭源交付：标准年度与永久授权不包含，必须另行评估并签署明确书面授权。
- 愿意继续遵守 AGPL-3.0 并公开对应源代码：不需要购买商业授权。

两种自营闭源授权都只覆盖一个授权主体和一个自营产品或品牌，包含授权主体控制的开发、测试、生产环境、闭源修改和向自身最终用户收费运营；不包含转让、转授权、多个独立产品、第三方交付、Twinkle Video 品牌权、后续版本、部署、定制开发、技术支持、模型 API 和服务器等费用。永久授权中的“永久”只表示授权书列明版本的使用期限，不表示永久更新或服务。

完整的允许事项、限制、授权期限、第三方组件边界和申请流程，以 GitHub 仓库中的[《Twinkle Video 商业授权说明》](https://github.com/csyqlz/VOZEB-PRO/blob/main/COMMERCIAL_LICENSE.md)为准。需要签约时可使用[商业授权协议模板](https://github.com/csyqlz/VOZEB-PRO/blob/main/COMMERCIAL_LICENSE_AGREEMENT.md)核对信息。公开说明和未签署模板不会自动授予商业权利，实际授权以项目方签发的授权书或双方合同为准。
